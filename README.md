# 🚆 IRCTC NextGen

An Online Railway Ticket Booking System that allows users to search trains, book tickets, and experience a basic railway reservation workflow through a web-based interface.

This project is developed for learning and demonstration purposes, focusing on core booking logic, user authentication, and basic payment simulation.

---

## 🔑 Key Features

### 👤 Guest Access
- Guests can freely visit and explore the website.
- Train and station information can be viewed without logging in or registering.

### 🔐 User Authentication
- Users must **register** and **log in** to book railway tickets.
- Secure login system to manage user bookings.

### 🚆 Trains & Stations
- The system contains a **limited number of predefined trains and stations**.
- Users can search trains based on available routes and stations.

### 💳 Dummy Payment Methods
- Ticket booking uses **dummy payment methods**.
- No real payment gateway is integrated.
- Payment success is simulated for learning purposes.

---

## 🛠️ Technologies Used
- Frontend: HTML, CSS, JavaScript  
- Backend: JDK 21, JSP, Servlet  
- Database: MySQL
- Server: Apache Tomcat

---

## 📌 How It Works
1. Guest users can browse the website without login.
2. To book a ticket, users must register and log in.
3. Logged-in users can search available trains and select seats.
4. A dummy payment process completes the booking.
5. Booking details are stored and displayed to the user.

---

## ⚠️ Disclaimer
This project is created for **educational purposes only**.  
All payment functionalities are simulated and **not real**.
